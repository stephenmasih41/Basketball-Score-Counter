# 🏀 Basketball Score Counter

A simple and interactive basketball score counter built with **HTML, CSS, and JavaScript**! 🏆  

## 🚀 Features
- 🏡 **Home Team Score:** Add +1, +2, or +3 points  
- 🏀 **Guest Team Score:** Add +1, +2, or +3 points  
- 🔄 **Reset Button:** Reset both scores to zero  

## ⚡ Tech Stack
- ✅ HTML  
- 🎨 CSS  
- 🎮 JavaScript  

## 💡 Future Improvements
- ⏰ Add a timer for the game  
- 🔊 Add sound effects when buttons are clicked  
- 🌙 Dark mode toggle
